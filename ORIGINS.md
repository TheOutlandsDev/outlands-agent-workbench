# Origins and licensing

OUTLANDS Agent Workbench was developed for TheOutlandsDev with AI-assisted coding
and review. Its Python engine, Linux check runner, Java launcher, arithmetic
fixture, and baseline tests adapt selected source from the owner's earlier
OUTLANDS Coding Agent prototype. The web controller, browser interface, targeted
edit support, and additional tests were developed for these milestones. Version 0.2 adds the
explicit-file project setup wizard, typed task checks, a fixed Java compile/main
runner, acceptance probes and two new invented example projects. The examples
illustrate digest verification and stable selection ordering; they contain no
real project or user data. Version 0.3 adds the prerequisite launcher and selected-file
Git workspace worker, controller/interface integration and their tests. Git is
invoked as a separately installed prerequisite; no Git implementation is bundled.
Version 0.4 adds private request measurements, sanitized diagnostic summaries,
the read-only Run Diagnostics interface, active/unresolved admission copy and
offline regression tests. These additions do not replay or resolve old requests.
Version 0.5 adds pure bounded snapshot search and line-range helpers, selected-file
tool integration, serialized chat-body limits, a read-only Context view and
offline regression tests. Version 0.6 adds selected-file hash refresh helpers,
reviewed task revisions, linked private revision receipts, refresh controls and
offline helper/controller acceptance checks. Its qualification fixtures are
invented Python and Java source; manual fixture corrections in acceptance do not
represent model-generated fixes. Revision data remains outside the public source
package. Version 0.7 adds a pure saved-run comparison reducer, guarded private
record loaders, read-only comparison endpoints/interface and offline regression
checks. Its Python/Java comparison histories are invented JSON records, not
model-generated patches or real-model qualification runs. Existing actual isolated-check
acceptance remains separate. All new fixture snippets are invented source text.
Qualification trials also used private copies of two existing offline planning
utilities with fictional inputs. Their source, proposed patches, histories and
records are not included in this public repository or newly licensed by it.

Only this reviewed adaptation is being published. No private repository history,
operational records, existing host control scripts, model prompts/responses,
credentials, live user data, or broader private projects are included. The
arithmetic fixture and test tokens/hostnames are invented examples.

No third-party JavaScript framework, copied UI template, external font, image,
vendored library, compiled binary, model weight, or bundled runtime is included.
The program calls separately installed Python, Java, Git, Bubblewrap, util-linux
`prlimit`, and optionally Ollama. Those projects and any selected model retain
their own terms; their presence as prerequisites does not change this source's
licensing status. Official protocol references are linked in the
[README](README.md).

A bounded online search using the public workbench name, schema identifier, and
filename combinations found no indexed matching implementation at review time.
This is limited provenance evidence, not proof of originality, complete ownership,
absence of copying, or license clearance. No third-party notices were removed.
